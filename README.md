# مرجع کاراکترهای برنامه‌نویسی

این پروژه شامل یک جدول مرجع تعاملی و زیبا برای **نام‌گذاری، معادل‌سازی و نام‌های ابتکاری کاراکترهای برنامه‌نویسی** است.

## ویژگی‌ها
- **۲۸ کاراکتر کلیدی برنامه‌نویسی** و نمادهای خاص.
- معادل‌های انگلیسی، تلفظ فارسی و نام‌های مصوب فرهنگستان.
- نام‌های ابتکاری دودویی (پایه-Open و پایه-Close) بر اساس کاربرد در کد.
- طراحی تک‌فایلی (`index.html`) واکنش‌گرا با فونت زیبای **Vazirmatn**، بدون نیاز به نصب هیچ‌گونه وابستگی یا سرور خارجی.

## نحوه استفاده
کافی است فایل `index.html` را در هر مرورگری باز کنید یا آن را روی **GitHub Pages** فعال کنید تا به صورت وب‌سایت آنلاین در دسترس باشد.



# Programming Characters Reference

This project provides an interactive and elegant reference table for **programming character naming, equivalence, and inventive terminology**.

## Features
- **28 essential programming characters** and special symbols.
- English names, Persian phonetic transcriptions, and official academy equivalents.
- Inventive base-naming pairs (Open/Close) based on actual code usage.
- Single-file (`index.html`) responsive design featuring the **Vazirmatn** font, with zero external dependencies or server requirements.

## Usage
Simply open `index.html` in any web browser, or host it directly via **GitHub Pages** for an instant online view.
